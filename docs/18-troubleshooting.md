# 排障手册 · 症状速查

> **用法**：遇到问题别从头读，**按 Ctrl+F 搜你在界面上看到的那句话**。
> 症状按**首字拼音**排序，方便扫。每条都指回详细说明在 `17-user-guide.md`（独立模式）或 `09-onboarding.md`（DSH 插件）。
> 本文只写**代码里真实存在**的行为与文案；尚未实现的能力一律标「当前版本没有」。

---

## 先做这三步（80% 的问题在这一步就解决了）

| # | 动作 | 为什么 |
|---|---|---|
| 1 | **确认服务活着**：浏览器打开 `http://127.0.0.1:3080/health`，能看到一段文字 | 服务不在，管理页、刷新、告警**全都不工作** |
| 2 | **确认你是哪种形态**：能打开 `/admin` → 独立模式；只能在 DSH 设置页找到「中转站管理」→ DSH 插件 | 两种形态入口不同，走错了会以为功能不存在 |
| 3 | **看「健康」那一栏**：在线 / 不可达 / 被拦截 / 未探测 | 这一栏直接区分「站点挂了」「网不通」「被 CF 挡」「还没查」 |

## 最容易被误判成「bug」的 6 件事

这六条**都不是故障**，先确认再报 issue：

| # | 你可能以为 | 实际是 |
|---|---|---|
| 1 | 「无限额度 · 已用 $34.58」= 我还有 34 块 | ❌ 是**已经花了** 34 块。无限额度没有"还剩多少"这个概念 |
| 2 | 「数据不足」= 功能坏了 | ❌ 观测不满 **3 天**就是不给数字。宁可说"不知道"，也不编 0 或 ∞ |
| 3 | 手工填的站不告警 = 告警坏了 | ❌ 用过期的手填数字告警只会吓你，所以**故意不告警** |
| 4 | 模型矩阵「未知」= 这个站没有 | ❌ 是**还没查过**。查过之后才会变成「有」或「抓过，确认没有」 |
| 5 | 某站「查不到」= 软件有 bug | ❌ **一部分中转站查不到余额是必然的**（站长关了接口 / 被 CF 挡 / 改过接口）。我们**绝不伪造 0**，所以宁可报错或让你手填 |
| 6 | 看到「**端口被占用**」= 出错了 | ❌ **如果你用 DSH，这正是它在告诉你「该去设置页，不该点这个快捷方式」**。以前要干等 30 秒，现在约 1 秒就给你这句指路——**它是提示，不是错误** |

## 什么时候真的该报 issue

带上这四样，能省一轮来回：

1. **形态**：独立模式 / DSH 插件
2. **你在哪一步**：双击桌宠 / 打开管理页 / 识别 / 添加 / 刷新
3. **界面上那句话**：原样复制（例如「健康探测失败：」「刷新失败：」）
4. **`<用户目录>\.dsh\dsh-pet\launcher.log` 的最后几行**

> ⚠️ **报 issue 时不要贴凭证**。界面只显示掩码，也请保持这样——`relay-credentials.json` 里是**明文**，别截图、别上传。

---

## 四条「不要做」

1. **不要用任务管理器杀桌宠** —— 会留半透明残影，也可能误杀同名进程。用「关闭桌宠」。
2. **不要同时开独立模式和 DSH 插件** —— 两边写同一份站点列表，**可能丢配置**。
3. **不要把 `relay-credentials.json` 发给任何人** —— 它是明文，等于把你的 Key 交出去。
4. **不要用「换端口」来绕开 DSH 占端口** —— 换端口后独立模式会和 DSH 并行跑，**两边写同一份站点配置，可能互相覆盖**。DSH 用户该做的是**去设置页**，不是换端口。
